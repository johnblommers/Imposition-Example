These files are the artifacts I produced in trying to 
learn more about making booklets using imposition.

`main.typ` is a short Typst script that generates a PDF with 
each page containing a centered huge page number. 

`main.pdf` is the result of `typst compile main.typ`.

`main-imposed.pdf` is the product of a long-forgotten
imposition program which took `main.pdf` and placed
four logical pages on each side of letter paper. This
file is printed directly to a printer with letter paper
in it.

To figure out how to fold and cut, well that's what the
big page numbers are for, to practice on and become a
bit more familiar with imposition. Written instructions 
for folding and cutting are confusing to me. With this
method it's obvious how to do the folding and cutting.
